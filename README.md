# Studio Ello (E Projetos e Interiores)

Site em Next.js, publicado no hub com o slug `/studio-ello` (ver `src/lib/base-path.ts`). Layout inspirado no template Solum (https://solum.framer.website/), com o terracota da identidade do studio como destaque.

- Conteúdo: Instagram [@e_projetos_interiores](https://www.instagram.com/e_projetos_interiores/) (posts e destaques) e avaliações reais do Google Maps ("Studio ELLO projetos") em `src/lib/data.ts`.
- Imagens otimizadas em `public/img`. Os originais ficam em `midia-original/` (fora do Git).

```bash
npm run dev   # http://localhost:3000/studio-ello
```
